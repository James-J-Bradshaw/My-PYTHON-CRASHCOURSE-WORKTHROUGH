### summary/ plan for game
In 'Alien Invasion', the player controls a rocket ship that appears at the bottom center of the screen. The player can move the ship right and left using the arrow keys and can shoot using the Spacebar.

When the game starts, a fleet of aliens fills the sky and moves across and down the screen, the player shoots down the aliens using his ship. If the player destroys all the aliens, a new fleet appears on the screen, who moves down the screen, faster than the previous fleet. If any aliens hit the player's ship or reaches the bottom of the screen, the player looses a ship. If the player looses 3 ships, then the game ends.
